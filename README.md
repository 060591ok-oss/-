# База даних — інтерактивний матеріал

Сторінка з теорією, компетентнісним завданням і тестом (інформатика).

## Як опублікувати на GitHub Pages
1. Створіть репозиторій і завантажте `index.html`.
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. Сторінка буде за адресою `https://<ваш-логін>.github.io/<репозиторій>/`.

Працює без бібліотек і без інтернету, також можна просто відкрити `index.html` у браузері.
